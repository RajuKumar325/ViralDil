# ViralDil Frontend Design Starter
Mobile-first short-video platform design. Brand: ViralDil. Maximum video duration: 10 minutes.
Includes public pages, separate Partner and Admin pages, shared responsive styling and basic UI navigation.

IMPORTANT: This is a design prototype, not a live platform. Authentication, database, real video uploads/storage,
AI dubbing, analytics, moderation actions, advertising and payments are NOT connected. No sample earnings
or fake real-world activity are shown. Connect secure backend services before launch.
Open index.html to preview. Keep all API keys and secrets out of GitHub.
